# Luccia na Arigolândia

Jogo de plataforma da Gocca Cosméticos. A Luccia cruza Porto Velho (floresta, Estrada de Ferro Madeira-Mamoré, Três Caixas d'Água e beira do Rio Madeira) protegendo o cabelo do ressecamento, do frizz, da química agressiva e do nó de fada.

- `index.html`: o jogo inteiro (HTML, CSS e JavaScript em um arquivo).
- `img/`: personagem, vilões, itens, cenários.

Para rodar localmente, sirva a pasta com qualquer servidor estático e abra `index.html`.

No topo do script de `index.html` ficam as configurações editáveis: cupom, textos dos ativos e a história de abertura.
